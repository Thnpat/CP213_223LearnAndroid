# 🐾 TailyTask

**TailyTask** คือแอปพลิเคชันจัดการงานและโปรเจค (Task & Project Management) ที่ออกแบบมาเพื่อเปลี่ยนการจัดการชีวิตที่น่าเบื่อให้มีความสนุกและน่าใช้งานมากขึ้น ด้วยดีไซน์แนว Minimalist Pastel พร้อมระบบสะสมแต้ม (Gamification) เพื่อสร้างแรงจูงใจในการทำภารกิจให้สำเร็จ

---

## 🚀 แนวคิดของแอป (Concept)
เปลี่ยน "รายการสิ่งที่ต้องทำ" (To-Do List) ให้เป็น "ภารกิจ" ที่มีรางวัลเป็นแต้ม เพื่อนำไปแลกเปลี่ยนธีมสีภายในแอป ช่วยให้ผู้ใช้รู้สึกเพลิดเพลินกับการจัดการงานในแต่ละวัน

---

## 💎 MVP (Minimum Viable Product)
ฟีเจอร์หลักที่เป็นหัวใจของแอปในเวอร์ชันแรก:
1.  **Dashboard**: แสดงภาพรวมงานและสถิติพื้นฐาน
2.  **Task Management**: ระบบเพิ่ม ลบ และขีดฆ่างานที่ทำเสร็จ
3.  **Points System**: ระบบบวกแต้มตามระดับความสำคัญของงาน (Low, Medium, High)
4.  **Theme Shop**: ร้านค้าสำหรับซื้อธีมสีด้วยแต้มที่สะสมมา
5.  **Calendar View**: ดูสถานะงานรายวันผ่านปฏิทินที่มีจุดสีบอกความสำคัญ

---

## ✨ ฟังก์ชันที่ทำเสร็จแล้ว (Phase 1 & 2)
ปัจจุบันแอปมีความสามารถดังนี้:
*   ✅ **AI Fast Record**: เพิ่มงานได้รวดเร็วผ่านการพิมพ์ข้อความแบบภาษาพูด (เช่น "พรุ่งนี้ 9 โมงมีสอบ") ระบบจะแยกวันและเวลาให้เอง (รองรับผ่าน Mock Gemini API)
*   ✅ **Project & Subtasks**: ระบบจัดการโปรเจคใหญ่ที่สามารถแบ่งเป็นงานย่อยได้ พร้อมหลอดแสดงความคืบหน้า (Progress Bar)
*   ✅ **Gamification**: ระบบสะสมแต้มจากการทำภารกิจสำเร็จ (งานย่อยในโปรเจคก็ได้แต้มเช่นกัน)
*   ✅ **Notification**: ระบบแจ้งเตือนล่วงหน้า 30 นาทีเมื่อใกล้ถึง Deadline
*   ✅ **Customizable Themes**: มีธีมพาสเทลให้เลือกซื้อถึง 6 รูปแบบ
*   ✅ **Calendar Updates**: แสดง Deadline ของโปรเจคใหญ่บนปฏิทินด้วยไอคอน 📁

---

## 🔮 ฟังก์ชันที่กำลังจะทำ/แผนในอนาคต (Future Phase)
*   🛠 **Login System**: ระบบสมาชิกเพื่อเก็บข้อมูลไว้บน Cloud
*   🛠 **Online Sync**: เชื่อมต่อข้อมูลกับ Firebase เพื่อให้ใช้งานได้หลายอุปกรณ์
*   🛠 **Real AI Integration**: เชื่อมต่อกับ Gemini API ของจริงเพื่อการวิเคราะห์งานที่ฉลาดขึ้น
*   🛠 **Social Features**: ระบบจัดอันดับกับเพื่อน (Leaderboard)
*   🛠 **Drag & Drop**: ระบบจัดลำดับงานด้วยการลากวาง เพื่อความสะดวกในการจัดลำดับความสำคัญ (Reordering tasks)

---

## 🛠 เทคโนโลยีที่ใช้ (Tech Stack)
*   **Language**: Kotlin
*   **UI Framework**: Jetpack Compose (Material 3)
*   **Database**: Room Database (Local Storage)
*   **Architecture**: MVVM (Model-View-ViewModel)
*   **Background Tasks**: WorkManager (สำหรับการแจ้งเตือน)
